LEARNING ATELIER — GitHub Pages + PWA (мобильная версия)

ЧТО ВНУТРИ
- index.html — приложение с адаптацией для небольших экранов и iPhone.
- manifest.webmanifest — параметры установки приложения.
- sw.js — кэширование оболочки для повторного открытия без интернета.
- assets/ — иконки приложения.

ВАЖНО ПРО СОХРАНЕНИЕ
Эта версия использует только GitHub Pages и localStorage. Данные хранятся отдельно в каждом браузере и на каждом устройстве. Автоматической облачной синхронизации между iPhone и компьютером нет.

ПЕРЕД ПУБЛИКАЦИЕЙ
1. Открой предыдущую версию в браузере, где хранится твой прогресс.
2. Перейди в раздел «Данные» → «Скачать резервную копию».
3. Сохрани JSON-файл. После публикации открой новую версию на том же устройстве и импортируй JSON через раздел «Данные».

ПУБЛИКАЦИЯ НА GITHUB PAGES
1. Войди на https://github.com/ и нажми New repository.
2. Назови репозиторий learning-atelier.
3. Выбери Public и нажми Create repository.
4. На странице нового репозитория нажми Add file → Upload files.
5. Загрузи содержимое этой папки: index.html, manifest.webmanifest, sw.js и папку assets целиком. Файлы должны лежать в корне репозитория, а не во вложенной папке.
6. Нажми Commit changes.
7. Открой Settings → Pages.
8. В разделе Build and deployment выбери Deploy from a branch.
9. В Branch выбери main, папку /(root), затем Save.
10. Подожди завершения публикации. Адрес будет примерно таким: https://ТВОЙ-ЛОГИН.github.io/learning-atelier/.
11. Открой опубликованный адрес по HTTPS. Первый запуск сделай с интернетом, чтобы приложение загрузило файлы для офлайн-режима.

УСТАНОВКА НА IPHONE
1. Открой опубликованную ссылку именно в Safari.
2. Нажми «Поделиться».
3. Выбери «На экран Домой» (если пункта нет — пролистай список действий вниз и найди его в редактировании действий).
4. При необходимости включи «Открывать как веб-приложение».
5. Нажми «Добавить». На домашнем экране появится иконка Atelier.

УСТАНОВКА НА ANDROID
Открой ссылку в Chrome → меню ⋮ → «Установить приложение» или «Добавить на главный экран».

УСТАНОВКА НА WINDOWS
Открой ссылку в Edge или Chrome. Используй значок установки в адресной строке либо меню браузера → «Установить приложение».

ОФЛАЙН-РЕЖИМ И ОГРАНИЧЕНИЯ
- Для первого кэширования нужен интернет.
- После первого успешного открытия приложение может запускаться без сети.
- Изменения сохраняются локально в браузере/на устройстве.
- Данные не синхронизируются автоматически между устройствами.
- Не очищай данные сайта/браузера, если не сделала резервную копию JSON.
- При публикации обновлений Service Worker обновит оболочку приложения при следующем подключении к интернету.

ПРИМЕЧАНИЕ
Название Learning Atelier оставлено без изменений. Его можно переименовать позже, одновременно обновив заголовок, manifest и подпись иконки.
